# Практика - гілка lesson14-01

    За допомоги сайту https://jsonplaceholder.typicode.com/ будемо відпрацьовувати практичну навички роботи з запитами

    Отримати список користувачів https://jsonplaceholder.typicode.com/users та відобразити на сайті

    Отримати альбоми користувача по айді https://jsonplaceholder.typicode.com/users/1/albums та отобразити у відповідному контейнері

    Отримавши айді альбома конкретного користувача, видягнути всі фото з цього альбому за роутом https://jsonplaceholder.typicode.com/albums/1/photos

    Демонстрація паралельності запитів отриманням списку всіх користувачів та альбомів

# Домашка

    Створити функціонал отримання списку постів кожного користувача з списку користувачів та відображення цього на сайті. 
    У кожному пості додати кнопку, що буде створювати відповідний запит до АПІ та повертати набір коментарів до цього посту.
    Коментарі теж слід вивести десь поруч з постом. 
    
    Додаткові бали будуть надані за орігінальну стилізацію та анімацію контенту.
